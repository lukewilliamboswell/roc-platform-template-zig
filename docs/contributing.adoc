= Contributor tasks and workflows

`release.yml` checks pull requests and pushes to main, and publishes only when
explicitly dispatched from main with a version. One Linux builder checks the
source and cross-compiles the host. All six native runners test the same bundle
and archived examples through Blueprint, including Intel macOS and Windows.
`CI required` and `Bundle required` remain the required checks.

[source,sh]
----
blueprint run check
blueprint run fetch-link-inputs
blueprint run build-release
blueprint run test-host
blueprint run test-expects
blueprint run release-test -- test-examples
blueprint run release-test -- test-examples --update
blueprint run bundle -- --output-dir .zig-cache/release-platform
blueprint run release-package -- build 0.0.1-dryrun --platform-bundle .zig-cache/release-platform
blueprint run sbom
blueprint run release-test -- test-archive
blueprint run docs
----

Use fresh bundle and release output directories. `release-test` needs only the
latest nightly as `roc`; it needs neither Zig nor Nix. The host and packaging
tasks fetch Zig 0.17.0 on all five systems and expect archive tools on PATH. `zig build test` prepares the native host and uses the shared examples
runner; run it inside `blueprint shell`.

The platform and examples carry no compiler pin. `nightly.yml` tests the latest
published platform against the latest nightly and maintains one tracking issue.
Only repository scripts use `roc-stable`, pinned in Blueprint.roc. Update that
tag and script headers together, then regenerate Blueprint.lock.
