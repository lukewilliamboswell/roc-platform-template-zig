# macOS interface provenance

`libSystem.tbd` is generated by this repository from the reviewed symbol catalog
in `libSystem.json`. It is project-authored linker metadata: the producer neither
reads nor copies an Apple SDK `.tbd`, framework, library, or binary.

The catalog records only names needed to resolve the platform's two macOS host
archives. Changes must include a native unresolved-symbol audit for both x86-64
and ARM64. The generated file identifies Apple's system library, but contains no
Apple implementation code. This provenance file and the catalog are shipped in
the release and platform bundle so recipients can distinguish generated interface
metadata from redistributed runtime code.
